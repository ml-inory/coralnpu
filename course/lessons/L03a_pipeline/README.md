# L03a · 流水线与冒险

**目标**：把 L01/L02 的单周期核改造成 **5 级流水线**（IF/ID/EX/MEM/WB），
并正确处理四类冒险：数据（旁路）、load-use（气泡）、控制（冲刷）、结构（冻结）。

## 前置

`./learn check L02` 通过（L03a 会复用你写的 `lsu.sv`）。

## 教材

* [`pdf/基础知识.pdf`](pdf/基础知识.pdf)：为什么流水线买的是频率而不是 CPI、
  五级结构、三类冒险与四种处理、两种停顿的区别、CPI 量化、与上游 4 级流的对照
* [`pdf/作业说明.pdf`](pdf/作业说明.pdf)：6 个 TODO 的分步说明、调试方法、
  6 条"作者踩过的坑"、进阶挑战（把 CPI 从 2.66 降到 2.2 以下）

## 你的任务

**只改一个文件**：[`rtl/pipeline_core.sv`](rtl/pipeline_core.sv)（6 个 TODO）。

管道的骨架（阶段寄存器、译码、ALU、LSU 连接）已经给你，你要补的是**冒险处理**：

| TODO | 内容 | 一句话 |
| --- | --- | --- |
| 1 | 旁路 | MEM→EX、WB→EX，让运算拿到最新的值 |
| 2 | WB→ID 写穿 | 寄存器堆同拍读写的问题 |
| 3 | load-use 停顿 | 冻结 PC/IF + 插气泡 |
| 4 | 控制冒险 | 分支/跳转在 EX 解析 → 冲刷 + 重定向 |
| 5 | 气泡控制位清零 | 否则被冲刷的指令会写寄存器 |
| 6 | 结构冒险 | 等 LSU 时冻结整条流水线 |
