# P0 分级提示

## 模块 A：命令跑不对

1. 先确认你在仓库根目录：`pwd` 的输出应该以 `coralnpu` 结尾；
2. `>` 会覆盖文件，`>>` 才追加——四条命令要按顺序执行，第二条用 `>>`；
3. 最后一条 `false; echo "exit=$?"` 里的分号表示「先执行 false，再执行 echo」，
   不能写成两个独立命令（那样 `$?` 就变成上一条 echo 的结果了）。

## 模块 B：找不到地址或符号

1. 先确认 ELF 生成成功：`ls -l course/work/P0/hello/`；
2. 符号表命令：`riscv64-unknown-elf-objdump -t course/work/P0/hello/hello.elf | grep answer`；
3. 找不到 `answer` 是因为它是 `volatile int`，会被放进 `.bss`；
   如果符号表里没有，改用 `course/work/P0/hello/symbols.json`（课程脚本生成的符号表）；
4. `first_sw` 是反汇编里第一条 `sw` 指令的机器码（形如 `02812623 sw ra, ...`），
   取前面那 8 位十六进制数。

## 模块 C：多数表决器

1. 真值表里 y=1 的行是 011、101、110、111；
2. 对应三个乘积项：`b&c`、`a&c`、`a&b`；
3. 把它们或起来就是答案；注意不要写成「至少一个为 1」（那是 `a|b|c`）。

## 模块 D：mux4 与 counter

1. `mux4`：`case (sel)` 的四个分支分别把 `d0..d3` 赋给 `y`，末尾要有 `default`；
2. `counter`：`always_ff @(posedge clk)` 里先判断复位：`if (rst) q <= 8'h00;`，
   再判断使能：`else if (en) q <= q + 8'd1;`；
3. 如果仿真输出里所有值都是 0，说明 `q <=` 那一行被复位分支挡住了，或者根本没写；
4. 如果计数器每次加 2，检查是不是在两个 `always` 块里都写了 `q`（多驱动）。

## 模块 E：指令字段

1. 机器码用 `objdump -d` 看，找到 `addi` 那一行最前面的 8 位十六进制；
2. `rd` 是目标寄存器（写结果的那个）：这里是 `a0`；
3. `rs1` 是源寄存器（被读的那个）：这里是 `a1`；
4. `imm` 是立即数，带符号：这里是 `-7`；
5. 想验证自己的理解，可以把二进制写出来按 32 位分组：
   `1111 1111 1001 0101 1000 0101 0001 0011`。
