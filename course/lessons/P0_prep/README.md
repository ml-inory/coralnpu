## 五个模块

| 模块 | 补什么 | 对应 L00/L01 里的哪一步 |
| --- | --- | --- |
| A | 命令行：重定向、管道、退出码、路径 | 所有作业都要用 |
| B | 从 C 到机器码：编译、链接、ELF、符号表、内存布局 | L00 作业 4、L01 整课 |
| C | 数字逻辑：组合逻辑、真值表、逻辑门 | L00 作业 3 的前提 |
| D | Verilog：模块、端口、组合/时序写法、测试平台 | L00 作业 3、L01 全部 RTL |
| E | RISC-V：寄存器、PC、指令格式、字段拆解 | L01 的译码与数据通路 |
