# L02 · 访存子系统（LSU）

**目标**：把访存从"核心里的几行组合逻辑"变成**一个独立模块 + 状态机**，
并让这个模块支持两件 L01 做不到的事：

1. **存储器有延迟**——发出请求后存储器可能忙若干拍，核心必须会等；
2. **非对齐访问**——跨字的 `lw`/`sw`/`lh`/`sh` 要拆成两笔对齐事务。

## 前置

`./learn check L01` 显示 `5/5 个用例通过`。L02 会用你的 `alu32`（L00）与 L01 的测试程序。

## 教材

* [`pdf/基础知识.pdf`](pdf/基础知识.pdf)：访存事务的构成、非对齐拆分算法、valid/ready 握手、
  状态机与"冻结核心"、与上游 slot 表 LSU 的对照
* [`pdf/作业说明.pdf`](pdf/作业说明.pdf)：三个 Step 的任务拆解、接口契约、调试方法、常见坑

## 你的任务

**只改一个文件**：[`rtl/lsu.sv`](rtl/lsu.sv)（4 个 TODO）。

核心部分（`tests/core_wrapper.sv`）由课程提供：它负责译码、ALU、寄存器堆，
并在 LSU 忙碌时冻结自己、在 LSU 完成时提交指令。这样你可以专心写访存子系统本身。
（如果你想把 L01 自己写的核搬过来替换它也可以，只要保持同样的握手语义。）

## 验收

```bash
./learn check L02              # 期望：12/12 次运行通过
./learn check L02 --only 06    # 只跑非对齐用例
./learn hint L02 2             # 卡住时的第 2 条提示
```

每个程序都会跑两种存储器延迟（`LATENCY=0` 和 `LATENCY=2`），两种都要过。
